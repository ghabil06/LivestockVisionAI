# Batch B2 Multi-Species Data Collection Standard Operating Procedure (SOP)

## 1. Scope and Equipment Setup

This protocol governs the field collection of photographic captures and certified physical measurements for Cattle, Chickens, Goats, and Sheep across research stations and partner farms.

### Equipment Checklist
1. **Calibrated Digital Platform Scale:**
   - Cattle scale: Certified capacity $\ge 1,500\text{ kg}$, precision $\le 0.5\text{ kg}$.
   - Small ruminant scale (Goat/Sheep): Certified capacity $\ge 250\text{ kg}$, precision $\le 0.1\text{ kg}$.
   - Precision bench scale (Poultry): Certified capacity $\ge 15\text{ kg}$, precision $\le 1\text{ g}$.
2. **Measurement Tape / Stick:** Calibrated rigid measuring stick for withers height and flexible tape for heart girth ($\pm 0.5\text{ cm}$).
3. **Primary Camera:** Smartphone or mirrorless digital camera ($\ge 12\text{ MP}$ resolution, fixed focal length preferred).
4. **Calibration Reference Marker:** 1.0-meter high-contrast visual checkerboard / fiducial reference stick.

---

## 2. Capture Protocol by Species

### 2.1 Cattle (*Bos indicus* / *Bos taurus*)
* **Distance:** $3.5\text{ m} - 5.0\text{ m}$ perpendicular to the lateral midline.
* **Camera Height:** Level with the animal's shoulder / withers ($\sim 1.1\text{ m} - 1.3\text{ m}$).
* **Required Views:**
  1. Lateral Left (entire profile from muzzle to tailhead, all four hooves visible).
  2. Lateral Right (mirror profile).
  3. Cranial Frontal (head and chest width).
  4. Caudal Rear (rump, pelvic width, and pin bones).
* **Dentition Close-Up:** Optional anterior lower incisor photograph for age confirmation.

### 2.2 Poultry / Chickens (*Gallus gallus*)
* **Distance:** $0.8\text{ m} - 1.2\text{ m}$.
* **Camera Height:** Level with bird body height ($\sim 25\text{ cm} - 35\text{ cm}$).
* **Required Views:** Lateral profile on uniform non-reflective matting with reference scale bar.
* **Ground Truth:** Scale weight recorded immediately prior to feeding. Hatch date recorded from flock ledger.

### 2.3 Goats (*Capra hircus*)
* **Distance:** $2.0\text{ m} - 3.0\text{ m}$.
* **Camera Height:** Level with withers ($\sim 65\text{ cm} - 80\text{ cm}$).
* **Required Views:** Lateral left, lateral right, rear view.
* **Oral Inspection:** Document number of permanent incisor pairs erupted (0, 2, 4, 6, 8 teeth).

### 2.4 Sheep (*Ovis aries*)
* **Distance:** $2.0\text{ m} - 3.0\text{ m}$.
* **Camera Height:** Level with withers ($\sim 60\text{ cm} - 75\text{ cm}$).
* **Wool Measurement:** Record fleece depth at mid-side using ruler ($\text{cm}$) and record shearing status (shorn / unshorn).
* **Required Views:** Lateral left, lateral right, caudal rear.

---

## 3. Data Integrity & Verification Checklist
1. All four images per animal must be acquired during the same recording session.
2. Animal scale weight must be measured within 30 minutes of photographic capture.
3. Animals must be held stationary; captures exhibiting motion blur ($\sigma^2 < 100$) must be retaken immediately.
4. All records must include scale model serial number and calibration certificate ID.
